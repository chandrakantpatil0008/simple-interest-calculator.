# Simple Interest Calculator

## Description

The Simple Interest Calculator is a basic calculator used to calculate the simple interest and total amount based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (P × R × T) / 100

Where:

* P = Principal amount
* R = Rate of interest
* T = Time period

## Example

If:

* Principal = ₹10,000
* Rate = 5%
* Time = 2 years

Then:

**Simple Interest = (10,000 × 5 × 2) / 100 = ₹1,000**

**Total Amount = Principal + Simple Interest = ₹11,000**

## Features

* Calculates simple interest
* Calculates total amount
* Easy to understand and use
* Suitable for basic financial calculations

## Conclusion

This project demonstrates the basic calculation of simple interest using the standard simple interest formula.
